# RD Studio – Website Jasa Pembuatan Website

Version: 1.0

Status: Draft

# 1. Overview

## Project Name

RD Studio

## Product Vision

Membangun website company profile modern yang berfungsi sebagai media pemasaran, portfolio, dan alat konversi untuk mendapatkan calon klien jasa pembuatan website.

Website harus memberikan kesan premium, profesional, cepat, dan terpercaya sehingga pengunjung terdorong untuk menghubungi melalui WhatsApp atau mengirim brief project.

---

# 2. Goals

## Business Goals

* Mendapatkan lead baru setiap hari.
* Menampilkan portfolio secara profesional.
* Menjelaskan layanan dengan jelas.
* Menampilkan harga secara transparan.
* Meningkatkan kredibilitas brand.
* Meningkatkan konversi dari visitor menjadi client.

## User Goals

Pengunjung dapat:

* Mengenal jasa yang ditawarkan.
* Melihat hasil pekerjaan.
* Membandingkan paket.
* Memahami proses pengerjaan.
* Menghubungi developer dengan mudah.
* Mengirim brief project.
